# 听觉专注力训练故事生成与打印

当用户要求：
- 生成/创作/增加听觉专注力训练故事
- 把故事转换为可打印PDF
- 去掉多余内容（目录、使用方法、小贴士）只保留故事

请按以下步骤执行：

## 1. 参考已有文档保持风格

先查找工作目录下已有的 `听觉专注力训练_故事手册*.docx` 或 `*.md` 文件：
- 用 `Glob` 搜索匹配文件
- 用 `PowerShell` 读取 `.docx` 内容（解压后解析 `word/document.xml`）
- 或直接 `Read` 已存在的 `.md` 文件

保持原有格式：
- 故事主角为可爱的动物
- 每篇包含：训练目标、故事正文、「❓ 提问环节」（4 道题）
- 提问覆盖：找茬、细节、数量、顺序、分类、推理、常识、安全判断等

## 2. 生成新故事

每次创作 10 个新故事，编号续接已有故事（如已有 1-10，则新篇为 11-20）。

把故事写入新的 markdown 文件，文件名包含日期：
- 完整版：`听觉专注力训练_故事手册_补充篇_YYYYMMDD.md`
- 打印版：不需要写入单独 markdown，直接生成 PDF

## 3. 生成打印版 PDF

创建只含故事内容的临时 HTML（排版紧凑、省纸）：
- 去掉标题页、文档日期、使用方法、故事目录、家长小贴士
- 保留：故事标题、训练目标、故事正文、提问环节
- 使用较小字号（10.5pt）和紧凑行距（1.45）
- 页边距设为 1.2cm~1.5cm
- 每个故事用细虚线分隔，避免分页时断裂

转换流程：
1. 用 `Write` 生成排版好的临时 `.html` 文件
2. 用 Microsoft Word COM 自动化把 `.html` 另存为 PDF
3. 删除临时 `.html`

输出文件命名：
- `听觉专注力训练_故事手册_补充篇_YYYYMMDD_打印版.pdf`

## 4. 常用工具

- `Read` / `Write` / `Edit`：读写 markdown
- `PowerShell`：读取 docx、调用 Word COM 生成 PDF
- `Bash`：创建目录等
- `Glob`：查找已有手册文件

## 5. 示例提示词

用户可以说：
- "再写10个专注力故事"
- "把这份故事转成PDF打印版"
- "去掉多余内容，只留故事生成PDF"
