## 一、产品概述

### 1.1 产品定位

「幼小衔接互动教程」是一款面向5-7岁学龄前儿童及家长的H5在线学习产品，涵盖语文、数学、英语三大核心学科，帮助孩子平稳过渡从幼儿园到小学阶段。产品采用游戏化学习理念，将知识点融入互动场景，提升学习趣味性与持续性。

### 1.2 核心目标

| 目标维度 | 具体描述 |
|---------|---------|
| 学习目标 | 掌握小学一年级基础语文、数学、英语知识 |
| 用户目标 | 每日15-20分钟轻松学习，养成自主学习习惯 |
| 商业目标 | 提升用户留存与课程转化率 |

### 1.3 目标用户

| 用户类型 | 年龄段 | 特征描述 | 核心诉求 |
|---------|-------|---------|---------|
| 学龄前儿童（主要用户） | 5-7岁 | 注意力集中时间短，喜欢色彩丰富、有声音反馈的界面 | 好玩、有趣、获得奖励 |
| 家长（付费决策者） | 28-40岁 | 关注学习效果与进度，偏好简洁明了的报告 | 看到进步、省时省心 |

### 1.4 使用场景

- **晨间学习**：早餐前10分钟，孩子自主完成当日语文朗读任务
- **睡前亲子**：家长陪伴下完成互动练习，查看学习报告
- **碎片时间**：外出等待时，利用零散时间进行知识复习

## 三、全局设计规范

### 3.1 视觉规范

| 元素 | 规范 |
|-----|------|
| 设计尺寸 | 375px × 812px（iPhone X 基准），向下适配至 320px |
| 色彩主调 | 暖米色 `#f5f0e8` 背景，深 slate `#2c3e50` 文字 |
| 强调色 | 翠绿 `#27ae60`（正确/通过）、暖橙 `#e67e22`（提示/警告）、朱红 `#c0392b`（错误/收藏） |
| 圆角规范 | 卡片 16px，按钮 12px，头像/徽章 50% |
| 字体规范 | 标题 18-20px PingFang SC Medium，正文 14-16px PingFang SC Regular |
| 安全区 | 底部留出 80px 导航栏安全区域 |

### 3.2 交互规范

| 场景 | 交互方式 |
|-----|---------|
| 页面切换 | 左右滑入滑出，200ms ease-out |
| 按钮反馈 | 点击时缩放至 0.96，松开后恢复 |
| 加载状态 | 骨架屏 + 旋转动画 |
| 成就/奖励 | 全屏 confetti 动效 + 音效反馈 |
| 返回顶部 | 页面下滑超过 3 屏时，右下角出现浮动按钮 |

**底部导航栏**

#### 4.4.2 页面间数据通信

**从课程页进入诗歌页**：
```javascript
// 课程页跳转示例
const poemUrl = `three-hundred-poem.html?mode=lesson&poem=${encodeURIComponent('静夜思')}&path=level1&from=chinese_module`;
window.location.href = poemUrl;
```

**诗歌页读取参数并适配UI**：
```javascript
// three-hundred-poem.js 需新增逻辑
const params = new URLSearchParams(location.search);
const mode = params.get('mode') || 'browse'; // 默认浏览模式
const targetPoem = params.get('poem');
const pathId = params.get('path');
const fromModule = params.get('from');

// 根据 mode 切换 UI
if (mode === 'lesson') {
    // 隐藏搜索框、侧边栏、收藏等
    document.getElementById('search-box').style.display = 'none';
    document.getElementById('menu-toggle').style.display = 'none';
    document.getElementById('bottom-nav').innerHTML = lessonModeNavHTML;
    // 显示返回路径
    document.getElementById('header-subtitle').textContent = `学习路径：${getPathName(pathId)}`;
}

// 如果有指定诗篇，自动进入详情页
if (targetPoem) {
    navigateToPoem(targetPoem);
}
```

**学习完成后的数据回传**：
```javascript
// 点击「完成学习」后
function completeLesson() {
    // 1. 记录学习进度到 localStorage
    const progress = JSON.parse(localStorage.getItem('poem_progress') || '{}');
    progress[currentPoem.id] = {
        completed: true,
        completedAt: Date.now(),
        path: pathId
    };
    localStorage.setItem('poem_progress', JSON.stringify(progress));

    // 2. 更新路径进度
    updatePathProgress(pathId, currentPoem.id);

    // 3. 返回课程页
    window.location.href = 'chinese-poem-module.html?path=' + pathId;
}
```

### 5.2 语音朗读交互流程

```
用户点击「朗读」
    │
    ├──→ 检测环境（微信内置浏览器？）
    │       ├──→ 是 → 提示「请在系统浏览器打开以获得语音功能」
    │       └──→ 否 → 继续
    │
    ├──→ 播放音频版（默认）/ 跟读版
    │       ├──→ 音频版：调用 Azure TTS API 播放
    │       └──→ 跟读版：逐句高亮 + Web Speech API
    │
    ├──→ 用户可控制：暂停/继续/停止/循环/调速/调音量
    │
    └──→ 播放结束 → 显示「朗读完成」提示
```

## 七、异常与边界处理

| 场景 | 处理方式 |
|-----|---------|
| 网络断开 | 显示「网络开小差了～」插画提示，已缓存内容可正常浏览 |
| 语音加载失败 | 显示「语音加载失败，请检查网络后重试」，提供重新加载按钮 |
| 指定诗篇不存在 | 显示「未找到这首诗」，3秒后跳转首页 |
| 微信内语音受限 | 首次进入检测环境，顶部显示常驻提示条 |
| 存储空间不足 | localStorage 写失败时降级为内存存储，不阻断流程 |
| 返回路径缺失 | `path` 参数无效时，默认返回古诗诵读模块首页 |

### 9.9 动画与过渡规范

#### 9.9.1 页面转场

```css
/* 页面进入 */
.page-enter {
    animation: slideIn 300ms ease-out;
}
@keyframes slideIn {
    from { transform: translateX(100%); opacity: 0; }
    to   { transform: translateX(0); opacity: 1; }
}

/* 页面退出 */
.page-exit {
    animation: slideOut 200ms ease-in;
}
@keyframes slideOut {
    from { transform: translateX(0); opacity: 1; }
    to   { transform: translateX(-30%); opacity: 0; }
}
```
